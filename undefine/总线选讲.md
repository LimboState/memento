# H0. 最简单的总线

```Plain Text
『 IFU 』--inst--->『 IDU 』
```

在单周期处理器中：
+ 主动发起通信的模块叫master(主设备)；
+ 响应通信的模块叫slave(从设备)；

单周期处理器定义该通信协议，如下：
+ master(IFU)往slave(IDU)发送消息(当前指令inst)；
+ 双方约定，只要master发送，slave理解收到；
+ 上述行为每周期都发生；

---

```Plain Text
『 IFU 』--inst+valid--->『 IDU 』
```

在更真实的处理器中：
+ IFU并非每周期都能取到指令；
+ IDU需要等待IFU完成取值后，才能进行译码；

通信协议，如下：
+ master(IFU)往slave(IDU)发送消息(当前指令inst)；
+ 双方约定，只要master发送，slave理解收到；
+ 上述行为仅在**valid**有效时发生；

---

```Plain Text
+-----+  ---inst+alid--->  +-----+
| IFU |                    | IDU |
+-----+  <-----ready-----  +-----+
```

在更真实的处理器中：
+ IFU并非每周期都能取到指令；
+ IDU需要等待IFU完成取值后，才能进行译码；
+ IFU需要等待IDU完成译码后，才能发送下一条指令；

通信协议，如下：
+ master(IFU)往slave(IDU)发送消息(当前指令inst)；
+ 双方约定，若master发送，且**ready**有效时，slave理解收到；
+ 上述行为仅在**valid**有效时发生；

>+ 这就是**异步总线**，在`valid & ready`时才发生，称“**握手**”；
>+ `valid & ！ready`时，master需要暂存消息，避免丢失；
>+ **使用valid和ready可以实现多级流水。**

# H1. 异步总线

**异步总线的RTL实现——接口信号**

Chisel提供了`Decoupled`模板，通过元编程轻松实现异步总线接口，`Decoupled`模板自带valid和ready：
```scala
class Message extends Bundle{
	val inst = Output(UInt(32.W))
}

class IFU extends Module{
	val io = IO(new Bundle{val out = Decoupled(new Message)})
}

class IDU extends Module{
	val io = IO(new Bundle{val out = Filpped(Decoupled(new Message))})
}
```

---

**异步总线的RTL实现——模块逻辑**

master和slave需要根据握手信号的情况来实现约定的总线协议
+ 不同情况做不同的事情(通信协议) -> 状态机
+ 总线的RTL实现=接口信号+状态机


master的状态转移图：
![[Pasted image 20261113203628.png|504]]
```scala
class IFU extends Module{
	val io = IO(new Bundle{val out = Decoupled(new Message)})
	
	val s_idle :: s_wait_ready :: Nil = Enum(2)
	val state = RegInit(s_idle)
	state := MuxLookup(state, s_idle, List(
		s_idle -> Mux(io.out.valid, s_wait_ready, s_idle),
		s_wait_ready -> Mux(io.out.ready, s_idle, s_wait_ready)
	))
	io.out.inst := //有指令需要发送
	// ...
}
```
