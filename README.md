**memento**，记忆碎片，是一个记录个人成长足迹的知识库。2026年11月11日，面对汹涌的AI浪潮，每个计算机专业的从业者都面临各方面涌来的压力，为了提高生产效率，每个工程师都需要和AI深入融合以全速推进项目，对于一个工作经验尚浅，知识底蕴并不深厚的计算机专业学生，AI剥夺了我们仅有的思考时间，加重了各方面的内卷和竞争。在这样起伏的时代，如何获得稳定和持续成长的成就感，变成了一个主要课题，memento是我用来记录我个人的学习成长的知识库，同理会整理一些知识，欢迎大家来相互讨论，一起进步，让我们在AI时代下保持宁静的心。

**一些方法论：**
+ 实践是检验真理的唯一标准，所有的学习都将建立在实践的基础上，将实践内容作为主线开展；
+ 为了保证每天的收获感，将时间划分为 60%工作、20%工作内容相关学习(回顾反思)、20%基础知识，且为了避免和时代脱节，每周必须抽出一天时间的50%学习当前AI的应用领域知识。
+ 不要逃避困难，遇到困难时，不能通过换一本书来获得虚假的成就感，一旦决定就有始有终。
+ 不必苛责完美！！！先做出一坨破烂出来。
